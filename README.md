# HafsahDansProject

# Deskripsi
Aplikasi shop yang menampilkan product list dan berbagai fitur lainnya dengan architecture MVVM.

## Fitur
- Tampilkan daftar produk
- Sortir produk berdasarkan harga
- Tambahkan produk ke wishlist (Realm)
- Detail produk lengkap termasuk gambar, harga, rating, dan deskripsi

## Stack yang di gunakan
- Swift
- UIKit
- Alamofire
- RxSwift
- Realm
- SnapKit

## Cara Jalankan
1. Clone repository
2. Buka `HafsahDansProject.xcodeproj`
3. Build dan run di Xcode
